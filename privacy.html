隐私政策

生效日期：2026年10月13日

本政策适用于 https://lumawayai.com 及其 www 子域（下称「本网站」）。运营者为北京溯光而行科技有限公司（下称「我们」）。

1. 我们收集什么

本网站是公司介绍页，不提供注册、登录、下单或在线支付。我们不通过本网站主动收集身份证号、银行卡号或生物识别信息。

你主动发信至 hello@lumawayai.com 时，我们会处理你写入邮件的姓名、邮箱、公司名和咨询内容，以便回复。

访问本网站时，托管方或浏览器可能记录常见技术日志，例如 IP 地址、访问时间、浏览器类型。我们不把这些日志用于画像或对外出售。

2. 我们如何使用信息

  • 回复商务或媒体咨询
  • 维护网站安全与可用性
  • 履行法律法规要求的配合义务

3. 共享、委托与跨境

我们不会出售你的个人信息。仅在以下情形向第三方提供必要信息：获得你的同意、为完成回复所必需、或法律要求。

本网站当前由 GitHub Pages 托管。访问时，相关技术日志可能由该服务在境外处理。如后续将网站迁至中国内地服务器，我们会同步更新本政策。

4. 保存与安全

咨询邮件按沟通需要保存，通常不超过实现回复目的所必需的时间，法律法规另有规定的除外。我们采取与信息敏感程度相称的访问控制。

5. 你的权利

你有权查询、更正、删除我们因邮件咨询而保存的你的个人信息，也有权撤回同意或投诉。请发信至 hello@lumawayai.com。我们将在核实身份后处理。

6. 未成年人

本网站面向企业与成年访客。我们不会主动收集未满十四周岁未成年人的个人信息。如误收集，请联系我们删除。

7. 政策更新

政策变更时，我们会在本页更新生效日期。重大变更会在官网显著位置提示。
